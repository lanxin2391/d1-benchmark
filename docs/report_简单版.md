# 给外行看的版本：网络先验到底给癌症基因排序带来了什么？

**（一个高中生也能读懂的项目总结 · 2026-11-12）**

---

## 摘要（先说结论，一段话）

给癌症基因排序，是生物信息学里最常做的事之一：如果你手上有一个新发现的突变，你想知道它**是"元凶"还是"乘客"**。现在的通行做法是"看它周围有没有别的已知元凶"——因为致癌基因往往扎堆出现在同一张分子网络里。这个做法通常被叫做"网络先验"。但一直有个说不清的问题：**这个方法到底帮了多少忙？** 它给出的排名变好了，是因为网络拓扑真的有信息，还是因为**那些被研究得多的基因，本来就既是元凶、又连接得多、还被引用得多**？我们做了一个专门测这件事的"考场"：**6 张网络 × 5 套标准答案 × 每个格子 200 次重复考试**，并且事先把评分规则写下来封存（学术上叫"预注册"）。结果是：**网络先验确实有用，但比文献里报的幅度小得多，而且很看标准答案是谁给的**；更要紧的是，在"哪些基因是癌细胞系必需"这种真正的功能任务上，**光靠"连接得多"（度）就够了，拓扑并没有再添什么**。这篇文章会把我们怎么做的、发现了什么、以及**哪些发现对我们自己不利**都讲清楚。

---

## 一、这个项目从哪里来（我们的好奇心）

想象你在给一群人排座次，想找出"最可能当司机"的那几个人。手里有一张地图：人和人之间有关系的连线。你排座次的规则是：**谁离"已知的司机"近，谁就更有可能是司机**。这是很自然的想法，也确实是现代分子生物学的常用做法——只不过"地图"换成了基因的相互作用网络，"已知的司机"换成了已知的癌症驱动基因。

问题是：这个规则到底准不准？

- 有人说很准。他们在自己的数据上，**排名指标提高了 0.1～0.2**（这在 AUROC 上是很大的提升）。
- 但也有同行早就提出过几个很扎心的反对意见，我们在文献里找到了最要命的几条：
  - **"连接多的基因，本来就更容易被研究"**。一个基因被研究得越多，它出现在各种数据库和论文里的次数就越多，地图上它的连线也就越多。Schaefer 等人 2015 年发现，"被当成诱饵（bait）用于实验的次数"和"连接数"的相关系数是 **0.52**；把这一层偏倚扣掉之后，**癌症组与对照组之间的"度"差异基本消失**。也就是说：你看到的"网络很准"，有可能只是"研究热度很准"。
  - **"图越大越准"**。Wright 等人 2025 年比较了 **45 张以上**人类分子相互作用网络，发现表现基本跟着网络规模走；一旦把"这张图覆盖了多少你的目标基因"控制住，这个效应就**塌掉**了。
  - **"换张考卷就换了个排名"**。Picart-Armada 等人 2019 年发现，**蛋白质复合物**（几个蛋白必须抱在一起才能干活）会造成"考试作弊"：如果同一个复合物里的成员被分到训练集和测试集两边，模型就等于提前看过考题。他们测出来，一个本来很强的网络分类器，**前 20 名里的正确命中从大约 12 个掉到不到 4.5 个**。
  - **Guala 与 Sonnhammer 2017 年的更大规模比较**给出了一个更尖锐的提醒：有一种带"度过滤"的**局部方法**（专门设计成不让高连接基因靠"连接多"取胜），在完整排名上**打败了**扩散类方法；扩散类只在最前面的 1–10 % 领先。**所以"用网络先验"这件事，答案取决于你用哪种先验。**

我们做的事，就是把上面这些疑问放进一个**统一、事先封存、可以复算**的框架里，用公开数据一次问清楚。

## 二、开始之前：把几个词讲明白（后面全靠这些比喻）

这一节是全文的"词典"，后面每一节都会用到这些比喻。

### 1. 基因、蛋白质、细胞、癌症

- **基因**：一段能造出蛋白质的说明书。人体有约两万个基因。
- **蛋白质**：说明书造出来的机器。机器之间会互相作用（一个蛋白帮助另一个蛋白工作，或者抑制它）。
- **细胞**：生命的基本单位。癌细胞就是失去控制的细胞。
- **癌症**：一群细胞因为几个"刹车失灵"而失去控制地增殖。这些"刹车失灵"的基因，就叫**驱动基因**（driver gene，癌基因 driver）。注意：**开车的**（driver）和**坐车的**（passenger）要分清——很多突变只是搭便车，没有造成癌；少数几个才是真凶。这个项目要做的，就是"从一堆突变里把开车的挑出来"。

### 2. 网络（我们的"地图"）

把每个基因画成一个点，把两个蛋白之间有已知相互作用的地方连一条线，这就是一张**网络**。我们用了六张不同的地图：

| 地图 | 它是用什么数据画出来的 | 规模（最大连通子图） |
|---|---|---|
| funmap | 用 CPTAC 泛癌**蛋白质组**数据 + 机器学习算出的"功能关联" | 10,189 个基因，196,605 条边 |
| intact | IntAct 实验数据库里的**蛋白—蛋白相互作用** | 17,918 个基因，564,706 条边 |
| string_phys700 | STRING 的**物理接触**子网络 | 9,830 个基因，85,576 条边 |
| rna_coexp | 我们自己用 CPTAC 的**mRNA**表达数据算的相关性网络 | 9,152 个基因，196,172 条边 |
| string_full700 | STRING 的**全部证据通道** | 15,882 个基因，236,712 条边 |
| reactome | **Reactome 通路**数据库（同一条通路的基因连在一起） | 3,953 个基因，20,143 条边 |

> **为什么用六张不同的地图？** 因为"网络"不是一个东西：有的来自实验、有的来自预测、有的来自文献整理、有的来自表达数据。如果只用一张地图，得到的结论可能只是那**一张地图**的特性。我们按"来源"把这六张分成三类（蛋白来源 3 张、RNA 来源 1 张、策展/文献来源 2 张），让"来源"成为一个可以研究的因素。

### 3. 度（degree）：一个基因连着多少个基因——"交通枢纽度"

**度**就是一个基因在图上连出的边数。**度特别高的基因**叫"枢纽"。这很关键，因为：

- 真实的驱动基因**确实是枢纽**（蛋白之间要互相作用才能协作）；
- 但**研究得多的基因也是枢纽**（你研究一个蛋白，就得测它和一堆别的蛋白的相互作用）。

所以"度"既是**混杂因素**，也是**竞争基线**。我们的主要指标，就是"网络先验比光看度强多少"。

### 4. 随机游走与重启（RWR）——我们用的"先验"

**随机游走（RWR）**可以这样理解：让一个"小 walker"站在某个已知的司机基因上，每一步**随机**走到一个邻居；走到某个基因的概率被当成"这个基因有多像司机"。关键设定是**重启**：每走一步有 5 % 的概率（这就是 α = 0.5 的意思）**跳回出发点重新出发**。这样得到的数就是"这个基因有多像已知的司机"。

> **为什么用 RWR，而不是别的？** 因为这是这个领域**最标准**的做法（RWR 由 Kohler 等人 2008 年提出，是"在网络上做 PageRank"），所以拿它当"典型代表"最有说服力。但我们**故意不调它**：一旦允许调参，我们衡量的东西就从"网络有没有贡献"变成了"我们调出了一个好方法"。**参数在开始分析之前就写死在预注册里**，任何后来的改动都必须记录在案。

### 5. AUROC：怎么比较两个排名的好坏

想象有两个榜单（我们的先验排一个，度排一个），每个榜上都有一些"确实是元凶"的基因。**AUROC** 衡量的就是：**随机挑一个真元凶和一个非元凶，随机那个真元凶排得更靠前的概率**。

- 完全瞎排 → **0.5**；
- 完美 → **1.0**；
- 0.7 大致意味着"随机抓两个，真元凶在前面的次数是七成"。

我们的**主要指标**是两者之差：**ΔAUROC = AUROC(网络先验) − AUROC(只���度)**。差值越大，说明网络结构额外提供了多少信息。

> **为什么必须跟"只看出度"比？** 因为只看出度已经很强了。**这是我们项目里对我们自己最不利的一个数字**：我们量到，只看出度的中位 AUROC 就有 **0.644**（最高 0.781），而我们的先验只把它抬到中位 **0.705**。所以"+0.081"这个数字听起来不小，**其实是在一个已经很强的基线之上的 9% 相对提升**。

### 6. 交叉验证：把考卷分成"练习题"和"考试题"

我们把数据反复分成 5 份：每次用 4 份当练习题（用来生成先验的"起点"——已知的司机），1 份当考试题（看能不能挑出真元凶）。这就是**交叉验证**。

为了更稳，我们把这件事做了 **40 遍**（40 个不同的随机划分，每个划分再分 5 折）→ 每个格子一共 **200 次"考试"**。40 这个数是**事先写在预注册里的**，不是为了好看才选的。

### 7. 置信区间与 bootstrap：重抽签

想知道"这个 +0.081 是不是碰巧"，有个朴素的办法叫 **bootstrap**：**把数据反复重抽**（有放回地重新抽签），每次算一遍，重复几千次，看结果散得有多开。散得开 = 不稳；聚得拢 = 稳。

我们的预注册特别指定了**按"基因"重抽**（叫 gene-cluster bootstrap），因为最该问的问题是："如果当初抽的是另一批基因，结论会变吗？"

### 8. p 值、FDR、置信区间：三个容易混的词

- **p 值**：如果实际上**什么也没有**，那么"看到现在这么极端的结果"的概率有多大。p 小 = 罕见。但 p 值**不是**"结论为真的概率"。
- **FDR（错误发现率）**：如果我们做了 24 次检验，允许有多大比例是假的阳性。我们只在**事先声明的那一族**检验里用 FDR。
- **置信区间**：如果把整个过程重复很多次，其中 95% 的区间会盖住真值。它比"p < 0.05"信息更多，所以我们主要用它。

### 9. 泄漏（leakage）：考试前看过考题

如果训练题和考试题里有"同一个人"（同一个蛋白质复合物、同一个基因），模型就能靠认人作弊。这叫**信息泄漏**。

我们做了专门的**复合物感知交叉验证**：**把整个蛋白质复合物固定在同一折里**，不许它跨考卷。

### 10. 预注册：考试前把答案和评分标准写下来封存

**预注册**的意思是：在看数据之前，把"我要检验什么假设、用什么统计方法、什么算成功"全部写下来，存到一个带时间戳、不可修改的公开仓库里（我们的预注册 DOI 是 **10.5281/zenodo.23121762**，2026-09-27 封存）。

它的作用是**防止我们自己作弊**：看到结果之后再改标准、换指标、挑一个显著的来讲——这是论文里最常见也最隐蔽的问题。**我们分析过程中所有偏离预注册的地方，都写进了"修订记录"（amendment）**，一共 A2.3a 到 A2.3k，外加把 14 类分析分别登记为"确认族"或"探索族"。

### 11. 负结果与"对自己不利的结果"

科学不只是"找到了想要的东西"。**没找到、或者找到了反面证据，同样是结果**，而且往往更有价值。我们的项目里有一条硬规矩：**对我们不利的数字，全部写进正文、写进摘要、并且提前准备好怎么回答**（有一份专门的"防守清单"）。

### 12. 稳定性：同一个学生两次考试差多少名

**稳定性**问的是："同一个基因，在两次几乎一样的考试里，排名差多少？"

我们发现了一件很反直觉的事：**整体结论很稳，单个基因很不稳**。臂级（一个格子的整体表现）的标准差只有 **0.0047**；但单个基因的分数本身波动 **18 %**，而且**一个中位基因在两次重划分之间会挪动大约 270 名**（在一个约一万名的榜上）。

## 三、我们到底做了什么（考场怎么搭的）

### 3.1 五套"标准答案"（我们管它们叫"标签"）

要衡量一个排名好不好，得先有答案。我们用了五套互相不完全一样的答案，每套都来自一个世界知名的大型策展项目：

| 答案（标签） | 它从哪来 | 阳性基因数 | 策展的"哲学" |
|---|---|---|---|
| intogen2024 | IntOGen（多种突变检测方法投票） | 633 | 看**突变频率** |
| ot_all | Open Targets（靶点—疾病关联，含文献通道） | 600 | 看**关联证据的广度** |
| ot_nolit | 同上，但**去掉文献通道** | 600 | 同上，去掉"被写过"的影响 |
| intogen_temporal_new | IntOGen 里**最新**发现的一批 | 152 | 同上，但专挑"新"元凶 |
| ncg_known | NCG（NCG 策展目录） | 708 | 人工策展 + 网络置信度 |
| （另有 clinGen） | ClinGen 临床有效性 | 84 | 临床专家小组的判断 |

> **为什么要五套？因为"标准答案"本身就是一种偏倚。** 一个基因是不是元凶，还取决于"谁在策展、用什么标准策展"。如果我们的结论只在某一套答案上成立，那它测的可能只是那套答案的策展口味。后面你会看到，这确实是一个大问题——**五套答案之间的重叠比我们想象的大得多**。

### 3.2 十一道"关卡"（每一个专门防一种作弊或夸大）

我们把文献里所有"会让结果变好看"的怀疑都做成了对照：

| 关卡 | 它防的是 | 结果 |
|---|---|---|
| 度匹配的随机种子 | 先验只是把高连接基因排前面 | 24 格里 23 格显著优于（z > 5） |
| 保持度分布的重连网络 | 信号来自"连线的形状" | 24 格里 23 格显著优于（z > 5） |
| 共享基因宇宙（1,605 个基因） | 基因集大小不同 | 效应掉到 **−0.036** |
| 时间切分（用更早发现的元凶） | 效应只存在于"过去" | **−0.0095 ± 0.0116** |
| 每网络统一阳性数 | 各标签阳性数不同 | **−0.0125** |
| 复合物感知交叉验证 | 复合物泄漏 | 泄漏从 **0.87–0.96 降到 0.02–0.18**；效应中位缩小 **14 %** |
| 去掉枢纽的 RWR（删边到每点度 ≤ K） | 效应只是"枢纽排名位置" | 最狠口径 **+0.0252**，8/24 格翻转 |
| 按发表量修正的标签 | 效应来自"研究热度" | IntOGen 标签上 **+0.0587**（仍为正） |
| bait 匹配的零模型（发表量配对） | 同上，更严格 | 见下 |
| 标签质量分层（策展强度） | 效应只在"弱阳性"里 | 见下 |
| ClinGen 17 % 噪声锚点 | 效应是标签噪声的产物 | 几乎无变化 |

### 3.3 四个"设计本身"的控制（别人不会问，但老师会问）

- **种子扰动**：把训练用的已知元凶随机删掉 10 %/30 %/50 %，看排名还稳不稳。
- **阳性数匹配诊断**：当 gene-cluster 区间有 4 个格子不通过时，那到底是"标签太小"还是"方法太严"？
- **标签冗余分析**：五套答案到底有几套是独立的？
- **第二个 learner**：把 RWR 换成"离已知元凶多近"这种局部方法，结论还成立吗？

### 3.4 外部检验：真功能数据（DepMap）

光在我们自己的目录上自测不够，所以我们要一个**完全独立**的功能答案：**癌细胞系里哪些基因是"必需"的**（敲掉它细胞就死了）。我们用了 DepMap 的 CRISPR 基因效应矩阵（**1,361 个癌细胞系**）和表达矩阵。

## 四、我们发现了什么

### 4.1 主结果：网络先验确实有用，但只在一个固定的方法下

| 事实 | 数字 | 白话 |
|---|---|---|
| 正向格子 | **23 / 24** | 24 个"网络 × 答案"的组合里，23 个上先验赢过度基线 |
| 中位提升 | **+0.081** | 平均多出 0.081 的 AUROC |
| 最好的格子 | **+0.171** | STRING 物理网络 × 去掉文献通道的 Open Targets |
| 最差的格子 | **−0.013** | Reactome × 最新发现的元凶（唯一为负） |
| 但基线本身有多强 | 度基线中位 **0.644** | 也就是说 +0.081 只是**在 0.644 之上再抬 9 %** |

### 4.2 我们的"主假设"判定：四种统计口径下成立，最严的那一种差 4 个格子

我们事先规定："**每个格子的 95 % 置信区间都要排除 0**"才算主假设成立。

- 四种区间构造（按折、按重复、按重复的 t 分布、按重复的 BCa）→ **24/24 全部成立**；
- 最保守的那一种（按基因重抽）→ **20/24**，失败的 4 个全是"最新元凶"那个答案。

我们**没有**把这条改小，而是**去查为什么**：在"每个答案阳性数都一样"的面板上重算 → 变成 18/24，**失败的不再只是"最新元凶"，连效果最小的 Open Targets 和 IntOGen 格子也开始失败**。所以那 4 个格子失败的原因是**效果太小（统计功效不够）**，不是"这个答案有问题"。这条我们在正文里写明了，也写进了摘要。

### 4.3 最大的发现：可见度能解释很大一块

**bait 匹配的零模型**是这么做的：给每个真元凶配一个**发表量相同**的假阴性，然后问"先验还能不能把它们分开"。

| | 匹配前 | 匹配后 |
|---|---|---|
| 全部格子的中位 | 17.6 % | **11.6 %** |
| 只看"最新元凶"答案 | 6.8 % | **4.7 %**（随机水平是 5 %） |

也就是说：**在最新的那个答案上，先验的优势和随机差不多**。这是我们项目里最重要的一个**负面结论**，而且它指向一个让整个领域都需要反思的问题：**文献里报的那些"网络先验带来的提升"，有多少其实是"研究热度带来的提升"？**

### 4.4 策展强度决定结果：效应集中在"证据强"的阳性上

我们给每个标签里的每个基因打一个"策展强度分"（ClinGen 看星数、IntOGen 看检测方法投票数、NCG 看文献数、Open Targets 看是不是只有文献支持），然后**只保留高强度的阳性**重算：

| 答案 | 高强度层 | 中强度层 | 低强度层 |
|---|---|---|---|
| intogen2024 | **+0.089** | +0.063 | +0.065 |
| 最新元凶 | **+0.074** | +0.012 | +0.023 |
| ot_all | **+0.112** | +0.091 | — |
| ot_nolit | **+0.110** | +0.078 | — |
| ncg | +0.067 | **+0.088** | +0.065 |

前四套答案都是"策展证据越强，效应越大"——**效应集中在证据扎实的阳性上**，这是好现象（说明不是噪声）。NCG 那一行反过来了：**因为 NCG 的"强度"本身就是文献数**，所以它的"高强度层"恰恰是度基线已经排得很准的那批基因，先验在那里自然没有增量。**两行合起来说的是同一件事：先验的增量，出现在策展证据薄、但网络结构能提供线索的地方。**

### 4.5 稳定性：端点很稳，单个基因很不稳——而且我们找到了原因

- **端点稳**：一个格子的整体表现，200 次评估的标准差只有 **0.0047**；
- **单基因不稳**：单个基因的分数波动 **18 %**，一个中位基因两次之间挪 **约 270 名**。

我们原来的猜测是"拥挤"（密集区域的基因不稳），**被数据否掉了**：两种"拥挤"的定义给出**相反符号**（一个 +0.478、一个 −0.175）。真正的原因是**基因自身的分数方差**（相关系数 ρ = **1.00**，即"这个基因有多不稳"几乎完全由"它自己的分数方差"解释），而所有经典拓扑指标（度、k-core、聚类、介数、PageRank、社区大小）**都解释不了**。

更进一步，这背后是一个**可以证明的定律**：RWR 对种子的权重是**线性**的，所以一个基因的分数基本就是"它周围有多少个种子"。**因此"把先验在多个随机划分上平均"（也就是 bagging）在数学上是无效的**——我们试了一个"稳定性正则化打分"，**恢复不了排名**。这是我们项目里第二个**明确的负结果**，也是老师点名要的分析。

**种子要多少才够？** 我们做了种子扰动实验：删掉 10 % 的种子，只损失 **1.9 %** 的效应（中位）；删掉一半，损失 **11.7 %**。真正决定损失的是**种子的绝对数量**：只有约 50 个种子的格子（Reactome × 最新元凶）掉一半就损失 **29 %**，而有约 470 个种子的格子只损失 **8 %**。

### 4.6 先验能迁移到"我们没标过的"元凶

我们用 NCG 目录做"仲裁者"：把**我们的答案里没有的** NCG 元凶（占 27 %）当作要检出的目标，看先验能不能把它们排到前面。

- **24/24 个格子为正**（中位 **+0.041**）；
- **26/26 个癌种**都为正（中位 +0.027）；
- 但在只看最前面的端点上只有 **13/24**，而且**只有四个蛋白网络全过**，funmap 和 RNA 共表达网络全不过。

**这说明**：先验确实能迁移到没见过的元凶，**但最前面那一段的排名是网络本身（蛋白网络）的性质，不是先验的功劳。**

### 4.7 我们的"负面清单"本身也是干净的

用 NCG 当仲裁者查我们的阴性集：**10 %–22 % 的留出阴性其实是策展过的元凶**（Reactome 的格子最严重）。

我们一开始的"事后清洗"给出的结论很惊人（IntOGen 的效应腰斩），但那是**假象**：事后清洗把评估集里的 NCG 基因连同 **87 % 的 IntOGen 阳性**（633 → 80）一起删掉了。**正确的做法是只清背景、阳性不动、整个基准重跑**，结果是：

- **23/24 格子仍为正，0 处符号翻转**；
- 中位效应 **+0.0809 → +0.0822**（几乎每个格子都略微**变大**）；
- 最保守的 gene-cluster 区间通过的格子从 20/24 变成 **21/24**。

**结论：阴性集确实脏，但脏的不是结论。**

### 4.8 哪些格子最弱

最弱的四个格子**全是"最新元凶"那个答案**（reactome × 最新元凶 **−0.0125**、intact × 最新元凶 +0.0071、rna_coexp × 最新元凶 +0.0127、funmap × 最新元凶 +0.0196）。

我们追查了这个现象，得到一个有意思的结论：**Reactome 在 2019 年的 NCG 目录上是正的（+0.089），在两个最新目录上是负的**。也就是说，**Reactome 的失败不是网络本身的失败，而是"策展滞后"**——它跟不上新发现的元凶。这正是我们事先提出的"策展滞后"假说所预测的，而且这是**第一个不依赖时间切分的检验**。

### 4.9 五套答案其实约等于一套

把五套答案的每网络均值拿出来互相预测（回归），R² 高达 **0.84（IntOGen）到 0.998（ot_all）**；用重叠矩阵的特征值算"有效维度"，只有 **1.54**。

**含义**：方差分解里那 30 % 的"标签主效应"，**主要是"这套答案好不好用"这一个共同因子**，而不是五种不同的策展哲学。**这也意味着"标签主效应"不是五份关于 driver 生物学的独立证据。**

### 4.10 换一个方法，结论就不成立

这是**我们最不利的一条**：我们用第二个固定方法（"离已知元凶多近"这种局部方法，而不是扩散）重跑，得到 **16/24 个格子为正、中位 +0.011**，而 RWR 是 +0.081；两个方法的效应相关系数只有 **+0.30**；在最密的 IntAct 上，第二个方法**每个答案都是负的**。

**含义**：**"网络先验比度基线强"这件事，取决于用的是哪种先验。** 这与 Guala 与 Sonnhammer 2017 年的公开结论一致。所以我们能说的只是**"在我们事先锁定并公开的那一个方法下，网络有可测的增量"**，不能说"任何网络先验都行"。

### 4.11 变一个"标准答案"，效应就缩水

| 对照 | 效应变成 |
|---|---|
| 每个答案阳性数统一 | **−0.0125** |
| 只用共同的 1,605 个基因 | **−0.036** |
| 复合物不泄漏 | 中位缩小 **14 %** |
| 去掉 STRING 的 database（文献）通道 | 效应**基本保留**（−0.025 / −0.038 / +0.006 / +0.010） |

最后一条是好消息：**我们担心的"面板和答案共享同一批上游知识"（Reactome → FunMap 的金标准 → STRING 的 database 通道），在这项测量里影响不大。**

## 五、这些结果对我们意味着什么

### 5.1 三句话版本

1. **在事先锁定的一个方法下，网络结构确实给"哪些基因是元凶"提供了超出"连接多"的信息**（24 格里 23 格，效应中位 +0.081），而且这个增量**能迁移到我们没标过的元凶**（24/24 格、26/26 癌种）。
2. **但增量不大，而且很挑答案**：最严的统计口径下有 4 个格子不成立；换一个标准答案效应就缩水；换一个方法结论就不成立；**五套标准答案其实约等于一套**。
3. **而且，其中相当一部分可以用"研究热度"解释**：发表量配对之后，"最新元凶"这个答案上的优势基本归零；而在真正的功能任务（癌细胞系必需性）上，**光靠连接度就够了，拓扑没再添什么**。

### 5.2 对做癌症研究的人意味着什么

- **别把"网络先验很强"当成结论**。如果你要拿一个网络先验的排名去筛实验靶点，请注意：那个提升可能大部分来自"这个基因被研究得多"。
- **先看你自己的答案有多强**。如果我们用"只看出度"就能到 AUROC 0.64，那么任何"先验"带来的 +0.08 都需要放在这个背景下解读。
- **在你最关心的那个场景上做检验**。我们的先验在"策展型 driver 答案"上有增量，在"功能必需性"上没有。这不是矛盾，是提醒：**先验的价值取决于你的下游任务是什么。**
- **多换几个答案、多个方法再下结论**。我们五个答案的相互可预测性高达 0.84–0.998，**单一答案上的漂亮结果很可能只是那套答案的策展口味**。

## 六、哪些发现对我们自己不利（这一节很重要）

我们把**对我们不利的数字全部列出来**，因为"只讲好话"才是真正危险的。每一行都配了我们准备好的说法。

| # | 对我们不利的事实 | 数字 | 我们的说法 |
|---|---|---|---|
| 1 | **度基线本身就很强** | 度中位 AUROC **0.644**（最高 0.781），先验只加 0.061，**相对增益 9 %** | "+0.081 是绝对值；相对一个 0.64 的基线只有 9 %——这也是我们主张效应有限的原因" |
| 2 | **预注册的主判定在自己的单位下不成立** | gene-cluster 区间 **20/24** | "四种区间 24/24，最严的 20/24；四个失败是效应最小的臂，等阳性数面板证明那是功效问题" |
| 3 | **换方法结论不成立** | 第二个 learner **16/24**、中位 **+0.011**、8 格为负 | "增量是方法特定的，所以我们只主张固定方法下的增量（已写进局限）" |
| 4 | **换指标效应大缩水** | pAUC **+0.031**、top-10 % **+0.041**（都 20/24） | "顶端排序的优势更小，所以我们不把 AUROC 读成召回率" |
| 5 | **外部功能任务上 degree 远强于先验** | K=30：先验 5.8 % / degree 69.2 % / 随机 3.1 %；K=100：47.6 % / 97.8 % / 6.1 % | "先验的增量是任务特定的；这与 bait 匹配零模型一致" |
| 6 | **每个控制都让效应变小** | 共享宇宙 −0.036、阳性数统一 −0.0125、时间切分 −0.0095、复合物 −14 %、最狠 hub-cap +0.0252（8 格翻转） | "每个控制都让效应变小，我们逐条报出来" |
| 7 | **可见度能解释一大块** | 17.6 % → 11.6 %；最新元凶 6.8 % → 4.7 %（随机 5 %） | "这是我们最重要的负结果：文献量解释了一大块" |
| 8 | **五个答案约等于一个维度** | 互相可预测 0.84–0.998；有效维度 1.54 | "标签主效应主要是共同的难度因子，不是五种策展哲学" |
| 9 | **单基因结论不可复现** | 每基因 CV **18 %**；中位基因挪 **约 270 名** | "端点稳、单基因不稳——这是实用上的边界" |
| 10 | **标签层面的"发表量 vs 效应"只有 4 个点** | ρ = +0.80，p = 0.20（n = 4） | "**样本太少，不足以立论**；可见度的证据只能是 bait 匹配零模型" |

> **第 10 条尤其要讲**：这一条看起来能支持我们的故事，但只有四个点、p = 0.20，**不足以支撑任何结论**。我们把它标出来，是为了避免自己在答辩时"顺手拿来用"。

## 七、我们还没做完的（局限与下一步）

| 局限 | 影响哪一句结论 | 下一步（已排进验证计划） |
|---|---|---|
| 最严的统计口径下 4 个格子不通过 | "效应在每个格子都成立" | 在一个**独立来源**的功能标签上重跑同样协议 |
| 阴性集被策展元凶污染 | 绝对数值 | 已用 Control 13 重跑（结论不变）；下一步再用 ClinGen 做仲裁者重复一次 |
| 评估是"自评自的"（用同一套策展逻辑既当标签又当标准） | 全部结论 | 做一次**盲测**：把候选基因交给独立专家组排序（Boutros 2014 的社区挑战模式） |
| 没有扰动实验 | 因果性 | 种子扰动已做（机制层面）；再做一次"改一个已知元凶，看预测怎么变" |
| 只测了一个方法 | "网络先验"这个说法 | 再跑两个方法族（PageRank/特征向量、局部距离），把"哪种先验真的有用"说清楚 |
| 上游知识库可能共享 | 面板的独立性 | E2 臂已做（去掉 STRING 的 database 通道，效应基本保留）；再量化 Reactome 派生的那一层 |
| 发表量与效应只测了 4 个标签 | 可见度故事的强度 | **双重匹配零模型**（发表量 + 度同时配对），给出"纯拓扑增量"这个数 |

## 八、名词小词典（术语 → 白话）

| 术语 | 白话 |
|---|---|
| 驱动基因（driver） | 真正造成癌的那个"刹车失灵"的基因 |
| 乘客突变（passenger） | 搭便车的突变，没有造成癌 |
| 相互作用网络 | 基因之间的"关系图"；点 = 基因，边 = 有已知关系 |
| 度（degree）/ 枢纽（hub） | 一个点连出的边数 / 度特别高的点 |
| 网络先验（network prior） | 用网络结构给基因排序的额外信息 |
| RWR（随机游走与重启） | 让小人从已知元凶出发随机散步、每步有概率跳回起点；走到的概率 = 有多像元凶 |
| α（重启概率） | 每走一步跳回起点的概率；我们锁死 0.5 |
| AUROC | 随机抽一个真元凶和一个非元凶，前者排更前的概率；瞎排 0.5、完美 1.0 |
| ΔAUROC | AUROC(先验) − AUROC(只看出度)，即网络结构额外贡献了多少 |
| pAUC | 只看最前面一小段的 AUROC（我们取 FPR ≤ 0.02） |
| 交叉验证 | 把数据分练习题/考试题，反复换着考 |
| 泄漏（leakage） | 训练题和考试题里有"同一个人"，等于提前看过答案 |
| 复合物 | 几个蛋白必须抱在一起才能工作的"小组" |
| bootstrap | 反复重抽签，看结论散不散 |
| gene-cluster bootstrap | 按**基因**重抽（预注册指定的重采样单位） |
| 置信区间 | 重复很多次时 95 % 会盖住真值的范围 |
| p 值 | 实际上什么都没有时，看到这么极端结果的概率 |
| FDR | 允许有多大比例的假阳性 |
| 多重比较 | 做很多次检验，总会有几次偶然显著 |
| 预注册 | 事前把假设、方法、成功标准写下来封存 |
| amendment（修订记录） | 对预注册的偏离，逐条记录 |
| 验证族 / 探索族 | 事先声明要检验的 / 事后做的分析 |
| 稳定性 | 同一个基因在两次几乎一样的考试里排名差多少 |
| 枢纽感知的 RWR（hub-cap） | 先删掉一些边，把枢纽效应压下去再跑 |
| bait 匹配零模型 | 给每个真元凶配一个"发表量相同"的假阴性 |
| 策展滞后（curator lag） | 策展型数据库跟不上新发现 |
| 度匹配随机种子 | 把真元凶换成"度相同"的随机基因，看效应还在不在 |
| 共享基因宇宙 | 所有格子都只用同一批基因，公平但更小 |
