## 3. 三句话版口头摘要（任何场合都能用）

网络拓扑相对节点度有可测但不大的增量（23/24 个臂、中位 +0.081 AUROC）；
对最强的经典基线是 +0.046（19/24），对第二个锁定方法是 +0.011（16/24）——
方向稳健、量级依赖方法。文献里那部分提升有相当一块来自**研究可见度**
（发表量配对零模型下 17.6 % → 11.6 %），这一条在两个方法下都成立。
我们自己最不利的三条也写在正文里：阴性集 10–22 % 被策展 driver 污染（但结论不靠它）、
DepMap 上先验不加码（K=30：5.8 % vs 度 69.2 %）、H2 结构性不可检验（最小可达 p = 0.1173）。
