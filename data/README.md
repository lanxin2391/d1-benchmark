# data/

`raw/` is not tracked by git. After downloading, the layout must be:

```
data/raw/
  networks/   funmap/  string/  reactome/  intact/
  labels/     intogen/  clingen/  opentargets_26.06/
  cohorts/    mc3.v0.2.8.PUBLIC.maf.gz
  reference/  hgnc_complete_set.txt  gene2pubmed.gz
```

This is exactly what the download script puts inside `D1_data/`: move the contents of `D1_data/`
into `data/raw/`.

`processed/` is generated by the scripts in `scripts/`. Small final panels (networks, labels,
splits) are committed at sync points; everything can be regenerated from `raw/`.
